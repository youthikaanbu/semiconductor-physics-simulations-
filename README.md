# semiconductor-physics-simulations-
matlab code for semiconductor simulations, understanding carrier flow in lattice, follows Solid State Electronics - Streetman &amp; Bannerjee

[Intrinsic Material](/intrinsic_material_lattice.m)
- seeing crystal with no impurities (this means no dopants)
- Temperature 
    - T = 0K: has no free carriers and behaves like an insulator 
    - T > 0K: thermal energy generates EHP (EHP only source of carriers in the intrinsic material)
- $n = p = n_i$ (electrons = holes = intrinsic carrier concentration)
